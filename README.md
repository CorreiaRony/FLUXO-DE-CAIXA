# Concilia Caixa — Omie × Modelagem

Projeto atual do conciliador financeiro para evolução via Codex.

## Arquivo principal
- `index.html` — versão V3 funcional do sistema.

## Regra central do produto
A investigação deve seguir esta ordem:
1. Consolidado mensal
2. Divergência por dia
3. Divergência por lançamento
4. Causa provável

O foco é **caixa realizado**. Projeto, centro de custo e categoria não devem impedir uma conciliação financeira quando data, tipo e valor sustentam o match.
